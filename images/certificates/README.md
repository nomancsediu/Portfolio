# Certificates Folder

Place your achievement certificate images here with the following naming convention:

## File Names:
- **Signature Hackathon** → `signature_hackathon.jpg`
- **UTA Programming Contest** → `uta_programming_contest.jpg`
- **AWS Networking Basics** → `aws_networking_basics.jpg`
- **Java (Basic) Certificate** → `java_(basic)_certificate.jpg`
- **Python (Basic) Certificate** → `python_(basic)_certificate.jpg`

## Naming Rules:
- Convert title to lowercase
- Replace spaces with underscores (_)
- Keep parentheses as they are
- Use .jpg extension

## Image Requirements:
- Format: JPG/JPEG
- Recommended size: 800x600 or higher
- Good quality for clear display in cards
